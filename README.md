## Glossary

- **SEO:** Search engine optimization. Improving a website to rank higher on Google and Bing.
- **AEO:** Answer engine optimization. Improving visibility in answers given by AI assistants.
- **SaaS:** Software as a service. Software that customers use online, usually by subscription.
- **Schema markup:** Code that helps search engines and AI understand what a page is about.
- **Local SEO:** Optimization that helps a business appear in searches for a specific city or area.
